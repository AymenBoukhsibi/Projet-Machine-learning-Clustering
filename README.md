# Machine Learning Project – Clustering Case

## 📌 Project Overview
This project focuses on **unsupervised machine learning**, specifically **clustering techniques**, with the goal of discovering hidden patterns and natural groupings within data.

All experiments, analyses, and visualizations are implemented in the Jupyter Notebook:
`Projet Machine Learning cas de Clustering.ipynb`.

---

## 🎯 Objectives
- Understand the principles of unsupervised learning
- Explore and preprocess the dataset
- Apply clustering algorithms to group similar observations
- Evaluate and compare clustering results
- Interpret clusters for data-driven insights

---

## ⚙️ Methods & Techniques
- Exploratory Data Analysis (EDA)
- Data preprocessing and scaling
- Clustering algorithms such as:
  - K-Means
  - Hierarchical Clustering
  - (Optional) DBSCAN
- Dimensionality reduction for visualization:
  - PCA

---

## 📊 Model Evaluation
Since clustering is unsupervised, evaluation is based on:
- Elbow Method
- Silhouette Score
- Intra-cluster and inter-cluster distance analysis
- Visual inspection of clusters

Plots and cluster visualizations are provided in the notebook.
